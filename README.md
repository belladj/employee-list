# employee-list
Employee List Project consisting of:
1. Login Page
2. Employee List Page
3. Employee Detail Page
4. Add New Employee Page

## How to run
1. Clone repository
2. Go to the repository using ```cd employee-list```
3. Install packages with ```npm install```
5. Run project with  ```ng serve```
6. Open page in ```localhost:4200``` as required

Depending on installation, some extra installations might required, such as ```@angular/material-moment-adapter``` and ```faker```

## How to build
```ng build```
