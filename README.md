# employee-list
Employee List Project consisting of:
1. Login Page
2. Employee List Page
3. Employee Detail Page
4. Add New Employee Page

## How to run
1. clone repository
2. install packages with ```npm install```
3. deploy  ```ng serve```
4. open page in ```localhost``` as required

## How to build
```ng build```
